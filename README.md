# Web-ohjelmoinnin sovellusprojekti

## Product Goal
Tavoitteena on luoda elokuvaharrastajille helppokäyttöinen palvelu, jossa elokuvien arvostelut, suositukset ja listat löytyvät helposti yhteisistä ryhmistä.

Palvelu tukee ihmisten yhteistä elokuvaharrastusta ja toimii tietokoneen sekä mobiililaitteiden selaimessa.
