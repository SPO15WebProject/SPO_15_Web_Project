## palvelu
### Must
- yhteisö ryhmät.
    - Ryhmä sivu näkyy elokuvat listat
    - Settings
        - Nimeäminen
        - invite only
        - admins
    - ryhmä search,
    - friend invites, accept invite. Suljetut porukat. Ryhmä lähteminen, potkut
    - Lisätä sivuja, ryhmä käyttäjä arvostelut
    - ryhmä chat
    - ryhmä admin
    - number of members
- tähti arvostelut 1-5, näkyy arvostelun antaja, aika
    - tarvii käyttäjätilin tekemään arvostelu
- toivelista, suosittelulista
    - listojen jakaminen, share link
    - ei tarvi käyttäjätiliä näkemään
    - ryhmä listat
        - ryhmä admin(s) voi muokata
- näkee tutun arvostelut
- elokuva haku
- käyttäjä voi heti selata elokuvia ilman kirjautumista
### Should
- ajankohtasia elokuvia, trending
- yksityisyys käyttäjälle, nickname
- arvostelu visibility, public, group only
- recommended movies, based on watched
- haku filtterit, näyttelijät, vuosihaku, flexible name search
- elokuva info: vuosi, näyttelijät, kesto, poster

    - elokuvatyypit
- englanti kieli
